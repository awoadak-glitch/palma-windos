# فحص تحديثات PALMA VISION

تتضمن الحزمة 49 تجربة Node.js: 25 فحصًا لإدارة الجلسات والبروتوكول ومسار
الأنمي، و24 فحصًا للتحديث. تشمل التحقق من المصدر والإصدار والحجم والبصمات،
الحزم التالفة، إلغاء التنزيل، منع تفعيل تنزيل ناقص، اعتماد إصدار جديد،
الرجوع بعد فشل البدء، عزل الطلبات، ومنع إعادة التشغيل أثناء تنزيل فيديو.

تشمل اختبارات المصدر المدمج فحص التحديث من تثبيت جديد بلا إعدادات، وتجاهل
رابط قديم محفوظ، ورفض تغيير الرابط من واجهة الطلبات. لا يعيد طلب الحالة
عنوان المستودع إلى الواجهة.

يفحص GitHub workflow التشغيل على Windows باستخدام Electron 44.7.2:
بدء النسخة المرفقة، استيراد تحديث ASAR، تأكيد الجاهزية من الواجهة المعزولة
عبر البروتوكول الحقيقي، ثم الرجوع بعد تحديث تجريبي معطوب. يتحقق أيضًا من
جاهزية زر التحديث وغياب حقول إعداد المستودع. لا تُنشر Release إذا فشل الفحص.
تظهر النتائج والسجلات لكل إصدار في صفحة Actions للمستودع.

يتحقق البناء من سلامة ملفات ASAR وZIP، وتتحقق عملية التنزيل من الحجم
وبصمات SHA-256 وهوية الحزمة قبل تجهيزها للتثبيت.
لا يوجد GitHub Token داخل العميل؛ مصدر الثقة هو HTTPS والمستودع المدمج.

لا تتضمن هذه الفحوص مشاهدة فيديو أو إصلاحات جديدة للقنوات.
