# PALMA VISION — Windows 2.4.0

تضيف هذه النسخة صفحة «تحديث بالما» في الإعدادات وقائمة التطبيق. ثبّت حزمة
Update-Setup مرة واحدة بجانب PALMA VISION.exe ثم شغّل ملف BAT المرفق.
بعد نشر المشروع في مستودع GitHub مخصص، أدخل رابط المستودع في صفحة التحديثات.

عند نشر إصدار أحدث، اضغط التحقق من التحديث، ثم التنزيل، ثم إعادة التشغيل
والتثبيت. تبقى المفضلة وسجل المشاهدة وهوية الجهاز في مجلد بيانات بالما نفسه.
يُحتفظ بالإصدار السابق للرجوع إذا لم يبدأ التحديث الجديد بصورة صحيحة.

هذه حزمة كود للتطبيق المحمول الموجود عندك؛ لا تتضمن محرك Electron أو FFmpeg.
قد تعرض خصائص EXE رقمًا قديمًا، بينما تعرض صفحة التحديثات إصدار الكود الحالي.
تحديث أوسكار يحتاج إصلاح توافق بالما أولًا ثم نشر الإصلاح في GitHub.

تحتفظ هذه النسخة بإصلاح إدارة جلسات أوسكار 1.1.7 الموجود في 2.3.1.
تفاصيل الفحص وحدوده في VERIFICATION-AR.md.
