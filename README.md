# PALMA VISION — تحديثات Windows

مستودع تطبيق بالما ونشر تحديثاته من داخل البرنامج.

## تفعيل التحديث في نسختك

إذا ثبتَّ إضافة التحديث 2.4.0، افتح **الإعدادات ← تحديث بالما** وأدخل:

```text
https://github.com/awoadak-glitch/palma-windos
```

اضغط **حفظ** ثم **التحقق من التحديث**. عند توفر إصدار جديد، اضغط **تنزيل التحديث** ثم **إعادة التشغيل وتثبيت التحديث**.

يُحتفظ بسجل المشاهدة والمفضلة والإعدادات. إذا لم يبدأ الإصدار الجديد بنجاح، يعود التطبيق إلى آخر إصدار مؤكد.

- [أحدث إصدار وحزمة التثبيت](https://github.com/awoadak-glitch/palma-windos/releases/latest)
- [حالة البناء واختبار Windows](https://github.com/awoadak-glitch/palma-windos/actions/workflows/palma-release.yml)

## نشر إصلاح جديد

1. عدّل كود التطبيق داخل مجلد `app`، واكتب وصف التغيير في `release.json`.
2. احفظ التعديل على فرع `main`.
3. يشغّل GitHub اختبارات الكود وتجربة تشغيل التحديث والرجوع عنه على Windows.
4. بعد نجاح الفحوص، ينشر إصدارًا جديدًا برقم `2.4.<رقم تشغيل workflow>`؛ يمكن تنزيله من داخل بالما.

التحديثات المنشورة اختيارية. تغيير أوسكار يحتاج تعديل توافق بالما أولًا ثم نشر الإصلاح هنا.
الحزمة تحدث كود التطبيق وواجهته؛ تغيير Electron أو FFmpeg أو bootstrap يحتاج حزمة تثبيت مناسبة.

## محتويات المشروع

- `app`: كود بالما والواجهة وآلية التحديث.
- `tests`: اختبارات الجلسات والبروتوكول والتحديث.
- `scripts`: أدوات التغليف والتحقق وملف تثبيت الإضافة.
- `.github/workflows/palma-release.yml`: اختبار Windows وبناء ونشر الإصدارات.

التفاصيل الفنية في [README-AR.md](README-AR.md).
