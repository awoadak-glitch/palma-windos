# تحديثات PALMA VISION عبر GitHub

نسخة 2.4.0 تضيف تحديث كود تطبيق Windows المحمول من داخل التطبيق. بيانات المستخدم تبقى في مجلد بالما نفسه، والتحديثات في مجلد فرعي مستقل. تثبت النسخة الجديدة بعد إعادة التشغيل، وتعتمد بعد بدء الواجهة؛ إذا فشل بدء التحديث تعود النسخة السابقة.

## تجهيز المستودع مرة واحدة

1. استخدم مستودعًا مخصصًا ضمن حساب `awoadak-glitch`، وفرعه `main`. يجب أن تكون Releases متاحة للعامة حتى لا يحتاج التطبيق إلى مفتاح GitHub.
2. ضع محتويات هذا المشروع في جذر المستودع: `app` و`tests` و`scripts` و`release.json` ومجلد `.github` بما فيه workflow. لا ترفع ملفات جلسات الاختبار أو هوية الأجهزة من خارج هذا المشروع.
3. فعّل Actions عند الحاجة. ملف `Publish PALMA update` يختبر الكود ويجرب تشغيل تحديث ASAR والرجوع عنه على Windows باستخدام Electron 44.7.2، ثم ينشر Release بعد نجاح الفحوص.
4. عند تثبيت النسخة الأولى: أغلق بالما، انسخ BAT ومجلد resources من Update-Setup إلى جانب PALMA VISION.exe، ثم شغّل BAT. يحفظ نسخة احتياطية قبل الاستبدال.
5. افتح الإعدادات > تحديث بالما واضغط التحقق من التحديث. المستودع مدمج في الحزمة، ولا تعرض الواجهة خانة رابط أو زر حفظ. لا تُستخدم إعدادات المستودع القديمة المحفوظة.

## نشر تعديل جديد

عدّل الملفات تحت `app` وارفع التعديل إلى فرع `main`. يُبنى الإصدار تلقائيًا برقم `2.4.<رقم تشغيل workflow>`؛ قد تتخطى الأرقام تشغيلًا سابقًا فشل قبل النشر. يمكن كتابة وصف التغييرات في `release.json` أو تشغيل workflow يدويًا. لا تعدّل ملفات الإصدار المنشور؛ انشر رقمًا جديدًا عند الإصلاح.

بعد ظهور Release ناجح، اضغط في بالما «التحقق من التحديث»، ثم «تنزيل التحديث»، ثم «إعادة التشغيل وتثبيت التحديث». تنزيل حزمة الكود حوالي ميغابايت واحد ولا يعيد تنزيل Electron أو FFmpeg.

تحديث أوسكار لا يصلح بالما تلقائيًا: نعدل توافق المصادر أو البروتوكول في كود بالما، ثم يصل هذا الإصلاح للمستخدمين بهذه الآلية.

## ما الذي يتحقق منه العميل؟

- رابط HTTPS لمستودع محدد داخل حساب المالك، وتحويلات تنزيل GitHub المعروفة فقط؛ لا تُرسل هوية أوسكار أو كوكي المشاهدة إلى GitHub.
- اسم التطبيق، رقم الإصدار، توافق bootstrap ومحرك التشغيل، الحجم وبصمات SHA-256 للملف المضغوط وASAR.
- فتح النسخة الجديدة وبدء كود الواجهة قبل اعتمادها. تُحتفظ آخر نسخة مؤكدة للرجوع، ويزال الأقدم بعد نجاح التحديث.
- ملفات جديدة بمسارات مشتقة من البصمة؛ لا تُكتب نسخة قيد التشغيل ولا تستبدل ملفات بيانات المستخدم.

البصمات تحقق سلامة الملفات؛ الثقة في النشر تأتي من حساب GitHub ورابط HTTPS، ولا يوجد توقيع Ed25519 مستقل. حافظ على صلاحيات النشر وحماية الحساب. لا تضع GitHub Token داخل تطبيق العميل.

## التحقق والبناء محليًا

```sh
node --test tests/*.test.mjs
python scripts/build-release.py --version 2.4.3 --repository awoadak-glitch/palma-windos
```

ملف `scripts/electron-smoke.mjs` يقبل المسار إلى Electron 44.7.2 ويختبر الإقلاع العادي، تحميل إصدار جديد من ASAR، وإعادة التشغيل على النسخة السابقة بعد تعطل تحديث تجريبي. لا يتصل بخوادم أوسكار.

هذه الآلية تحدث كود التطبيق وواجهته فقط. تغيير نسخة Electron أو FFmpeg أو bootstrap يتطلب حزمة كاملة مناسبة. تغليف هذه النسخة يحتفظ بمحرك Windows المحمول الأصلي. مشكلة تشغيل القنوات السابقة لم تدخل ضمن هذا التغيير.
